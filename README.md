# Ordex API

Small Go + SQLite API plus a React PWA for retailer ordering. The PWA keeps its shop profile in local storage and its catalogue cache, cart, drafts and order history in Dexie. This service only supplies the catalogue and receives submitted order snapshots.

## PWA

The Vite frontend is at the repository root. It is mobile-first, installable, has a virtualized catalogue, and safely queues an order locally when the API is unavailable.

```sh
npm install
npm run dev
```

Set `VITE_API_URL` to the public Go API URL when deploying to Vercel. Without it, local development uses `http://localhost:8080`.

```sh
VITE_API_URL=https://api.example.com npm run build
```

Deploy the project to Vercel as a Vite app. Set `VITE_API_URL` in Vercel Project Settings → Environment Variables; Vercel will run the `npm run build` build command automatically.

## Run locally

```sh
go run .
```

It runs at `http://localhost:8080` and creates `ordex.db` beside the source. Use `DATABASE_PATH` to place the SQLite file elsewhere and `PORT` to change the port.

## Endpoints

- `GET /health`
- `GET /api/catalogue`
- `POST /api/orders`
- `GET /admin` (staff dashboard)

## Admin dashboard and product CMS

Open `http://localhost:8080/admin` to review orders, search by shop/mobile/order number, filter by date, open a shared shop location, and export CSV. The **Products** section lets staff add, edit, deactivate, and delete catalogue items.

The local development login is `admin` / `ordex-admin`. Before deploying, set a strong `ADMIN_PASSWORD` environment variable on the Go API host.

Prices are integer paise, avoiding floating-point currency errors. `clientOrderId` must be generated by the PWA (for example `crypto.randomUUID()`); repeated submissions with the same ID return the existing order number.

`POST /api/orders` body:

```json
{
  "clientOrderId": "018f7fa3-0b4f-7b54-a2d6-07d7cf2bd261",
  "shop": {"storeName": "Gupta General Store", "customerName": "Amit Gupta", "mobile": "9876543210", "address": "Main Market"},
  "items": [{"productId": "prd_surf_1kg", "sku": "SURF-1KG-12", "name": "Surf Excel Easy Wash 1 kg", "unit": "case", "quantity": 2, "rate": 178800}],
  "notes": "Morning delivery preferred"
}
```
